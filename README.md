# CineSpin

CineSpin — это десктопное приложение для случайного выбора фильмов из списков платформы Letterboxd с помощью интерактивного колеса фортуны. Проект призван упростить процесс выбора кино для одиночного или совместного просмотра.


## Что умеет делать

*   **Загрузка готовых списков фильмов**: Вы можете загрузить так и собственный вотчлист, так и публичный, доступный из раздела
Lists в Letterboxd;
*   **Подбор пересекающихся фильмов**: Выберите друзей, и приложение само найдёт фильмы, которые добавлены в списки у каждого из вас, оставив на колесе только общие варианты;
*   **Управление колесом вручную**: Размер и прокручивание колеса можно изменять самостоятельно;
*   **Настройка состава колеса**: Состав колеса и списка фильмов легко регулируются простыми манипуляциями мышью.

## Инструкция по использованию

1.  **Для одного пользователя**: Введите свой никнейм на вкладке «Один» и нажмите «Загрузить вотчлист». Обратите внимание, что ваш профиль на Letterboxd должен быть открытым (публичным) в настройках сайта;
2.  **Для нескольких пользователей**: Перейдите на вкладку «Несколько», введите никнеймы через запятую и запустите загрузку, чтобы найти общие фильмы;
3.  **Для публичного списка/топа**: Скопируйте ссылку на любой список с сайта Letterboxd, вставьте её на вкладке «Списки» и нажмите кнопку загрузки;
4.  **Поиск и ручная настройка**: Если список получился огромным, используйте строку поиска под ним, чтобы быстро найти нужную картину. Вы можете вписать фильм вручную через верхнее поле, выкинуть лишнее двойным кликом или перетащить мышкой фильм на колесо;
5.  Нажмите зелёную кнопку «КРУТИТЬ КОЛЕСО» и пускай удача решит за вас.

## Установка и запуск

### Запуск из исходного кода
Для работы приложения необходим Python версии 3.10 или выше и установленные зависимости.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd CineSpin
   ```
2. Разверните виртуальное окружение и установите необходимые пакеты:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   venv\Scripts\activate     # Для Windows
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python app.py
   ```

### Готовая сборка (Windows)
Приложение скомпилировано в исполняемый файл для операционной системы Windows.
1. Перейдите в раздел **Releases** в правой панели текущего репозитория.
2. Скачайте последнюю версию архива и запустите файл `CineSpin.exe`.
