# CineSpin

> Рулетка фортуны для ваших фильмов на Windows

CineSpin - это десктопное приложение, которое позволит вам выбрать фильм посредством колеса фортуны. 

Данное приложение разработано с целью обеспечить простым и развлекательным путём выбрать фильм, которые планируете посмотреть.

---

## Инструкция

Вы можете так и ввести любой фильм, так и ввести свой ник из Letterbox (ВАШ WATCHLIST ДОЛЖЕН БЫТЬ ПУБЛИЧНЫМ), затем нажать на кнопку "КРУТИТЬ КОЛЕСО". Удача покажет вам, какой фильм посмотреть.
